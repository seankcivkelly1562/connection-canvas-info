## Project Overview

Connection Canvas provides a small, static web presence for the public pages associated with an iOS app. It uses GitHub Pages to publish an app landing page, privacy information, and support guidance without depending on a dynamic server or backend.

The layout is intended to make important destinations easy for app users, store reviewers, and support contacts to find. Since the pages are plain static HTML, App Store Connect links and other content can be maintained with minimal overhead.

## Using the Site

The published website can serve as the app's central public address for landing content, privacy details, and support resources.

A normal update cycle looks like this:

1. Modify the HTML pages with the latest app information.
2. Check and revise the App Store Connect or other store destinations as needed.
3. Commit the updated files.
4. Allow GitHub Pages to rebuild the site.
5. Provide the resulting URL to users, testers, or review teams.

Example deployment flow:

- Change the page content in the repository
- Push the updates to the main branch
- Confirm the live site at `https://seankcivkelly1562.github.io/connection-canvas-info/

## Site Settings

There is no separate configuration service. Site behavior and content are managed inside the static HTML files.

Review these areas when making changes:

- App name and visual branding text
- Privacy policy wording
- Support contact information and help instructions
- App Store Connect URLs
- GitHub Pages base path and publication location

To redirect a page to a different destination, edit the appropriate anchor in the source HTML and publish the updated files again.

## Frequently Asked Questions

**Which hosting service is expected?**  
The project is set up with GitHub Pages in mind, although the same static files can also be hosted by another static web provider.

**How can I revise the privacy or support content?**  
Edit the corresponding HTML files, commit the changes, push them to the repository, and publish the updated version.

**Can the app destinations be changed?**  
Yes. Update the App Store Connect and related URLs in the relevant source pages.

**Why might a new version not appear immediately?**  
Review the GitHub Pages publishing configuration, make sure the newest commit has been pushed, and wait for the rebuild before refreshing the live address.

**Does Connection Canvas require a backend?**  
No. It is a static website intended for app landing pages and support content.
